# 🥗 속편한 식탁: 한국형 저포드맵 식사 판정 · 개인 트리거 탐색기

> 2026 의료·건강 AI 소프트웨어 경진대회 · **14조** · 「생물정보학및소프트웨어코딩」

과민성 장증후군(IBS) 환자가 **먹은 한국 음식이 저포드맵인지 판정**받고, **식사·증상 일지에서 나에게 맞지 않는 성분(트리거)을 통계적으로 찾아내는** 웹앱입니다.

⚠️ **교육용 프로토타입입니다.** 진단·치료·처방 도구가 아니며, 포드맵 수치는 공개 문헌 기반 근사치입니다.

## 6. 핵심 알고리즘 요약

**식사 판정:** 재료 부하 = 먹은 양 ÷ 고포드맵 기준량. 같은 성분끼리 더해서 ≥1.0이면 🔴. '주의' 재료가 있거나 여러 재료가 쌓여 >0.5이면 🟡.

**트리거 분석:** 식사 1끼를 관찰 단위로 봅니다.
- 노출 = 성분 부하 ≥ 0.5
- 결과 = 식후 1~8시간 안에 4점 이상 증상

노출·비노출 식사의 증상률을 Beta(1,1) 사후분포로 비교해 P(노출>비노출) ≥ 0.99이면 '의심 높음'으로 판정합니다. 가장 강한 요인을 확정한 뒤에는 그 요인이 없는 식사만으로 나머지를 다시 검정합니다(동반 섭취 혼동 감소).

**검증 결과 (가상 환자 300명, 28일 기록):**

| | 정밀도 | 민감도 | 환자당 거짓경보 |
|---|---|---|---|
| v2 (최종) | 81% | 41% | 0.15 |
| v1 (초기) | 55% | 54% | 0.69 |

## 7. 안전·윤리

- 실제 환자 데이터를 사용하지 않았습니다. 모든 데모·검증 데이터는 합성 데이터입니다.
- 기록은 서버에 저장되지 않습니다. 브라우저 세션에만 머물고, 사용자가 JSON으로 직접 보관합니다.
- 경고 증상(혈변, 체중 감소, 야간 증상, 50세 이후 발병, 빈혈·발열, 가족력)이 있으면 진료를 먼저 안내합니다.
- 장기간의 과도한 제한식을 피하도록 재도입 단계를 안내합니다.
- Monash University FODMAP 데이터베이스는 복제하지 않았습니다.

## 8. 한계

- 포드맵 기준값은 문헌 기반 근사치이며, 한국 음식 상당수는 직접 측정 자료가 없어 레시피 재료로 추정했습니다.
- 레시피 자동 계산은 '일반적인 레시피' 기준입니다. 식당·가정마다 마늘·양파 양이 크게 다르므로 결과 표를 확인·수정해야 합니다. 판단이 애매한 파 종류는 고포드맵 쪽(흰 부분)으로 보수적으로 매칭합니다.
- 연관성 분석이므로 인과관계를 보장하지 않습니다. 기록 누락과 레시피 차이가 결과에 영향을 줍니다.
- 검증은 가정한 증상 모델 위의 시뮬레이션이며, 실제 환자에서의 성능은 확인하지 않았습니다.
- 한국 식단은 거의 매 끼니 프럭탄이 들어 있어 비교군이 부족하므로, 제한기와 재도입으로 보완해야 합니다.
