## 3. 보고서 목차 (본문 8~12쪽): 심사 항목과 연결

1. **문제 정의** (중요성·사용자 20점): IBS 유병률, 저포드맵 식단 근거, 한국 식단의 특수성(마늘·양파·밀·유제품), 기존 앱의 한계
2. **사용자**: 의사에게 IBS 진단을 받은 성인, 영양사 상담과 함께 사용
3. **데이터** (데이터·생물의학 타당성 20점): FODMAP 6개 하위그룹 생리(삼투·발효), 기준값 문헌, DB 구축 방법, 근거 수준, Monash DB를 쓰지 않은 이유
4. **구현** (완성도·재현성 25점): 구조도, 판정 규칙, 분석 알고리즘, 실행 방법·링크
5. **검증** (검증·안전성·한계 20점): ① 단위 테스트(known-answer) ② 시뮬레이션 300명 v1 vs v2 ③ 단순 빈도법과 비교 ④ 성분별 탐지율과 만니톨·프럭탄 문제 ⑤ **레시피 파싱 정확도**: 공공 레시피 50개를 무작위로 골라 사람이 정답(재료·g)을 만들고 자동 매칭률·g 오차를 측정, AI 추정 레시피와 공공 레시피 비교
6. **안전성**: 경고 증상 안내, 개인정보 비저장, 과도한 제한 방지, 진단 도구 아님
7. **한계와 발전 계획** (창의성·확장성 10점): 실제 측정 자료 확충, 사진 인식 입력, 영양사 공유 리포트, 웨어러블·월경 앱 연동, IRB 승인 후 실제 사용자 연구
8. **팀 기여도** (5점)
